# Security Policy

## Experimental status

PVC-RotHash-0 is an unreviewed cryptographic research prototype.

Do not use it for:

- password storage;
- digital signatures;
- certificates;
- software-update verification;
- file-integrity protection;
- authentication;
- key derivation;
- blockchain or proof-of-work systems;
- any production security boundary.

## Reporting a weakness

Please open a GitHub issue containing:

- affected version or commit;
- attack class;
- exact input pair or reproduction procedure;
- measured complexity;
- expected generic complexity;
- source code or script when available.

A weakness is a successful project result. The purpose of version 0 is to
discover structural failure as early as possible.
